How to read the map

USGS earthquakes — drawn at the true epicentre. Size and colour follow the official magnitude.
M<2 · 2 · 3 · 4 · 5+
Device estimate — how big and how far the sensor alone thinks the quake was. The direction is not measured: it is borrowed from the matched USGS event so the marker can be drawn as a point.
Distance ring — no USGS match, so the quake lies somewhere on this circle. A single station knows a distance, never a bearing.
The station — an Arduino UNO Q and a MEMS accelerometer, downtown LA.
