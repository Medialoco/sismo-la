How to read the map

USGS earthquakes (official catalog) — circle at the true epicenter, color/size = magnitude: <2 · 2-3 · 3-4 · 4-5 · 5+
Device estimates — how big and how far our sensor alone thinks the quake was. Direction is not measured: it is borrowed from the matched USGS event so the marker can be drawn as a point. Only the radius and the magnitude are the device's. The dashed line is its error — watch it shrink as calibration improves.
Distance ring — no USGS match yet: the quake is somewhere on this circle (a single station knows distance, not direction).
Station — the Sismo-LA device (UNO Q + IMU), downtown LA.
